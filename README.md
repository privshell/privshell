**Android power user, 10+ years in — now focused on ADB, and on designing and building root tools and modules.**

I poke at how Android apps actually behave once you're past the UI: permissions, system settings, logs, and the privileged access ADB and root give you. I design and build tools and root modules that make that process faster.

---

### about

- Testing and triaging Android apps, mostly through **ADB shell** and **root**
- Writing small scripts/tools when an existing one doesn't do what I need
- Contributing where I can to open-source Android tooling — even small fixes count
- Still learning; this is a hobby that occasionally turns into something useful for others
